# BookedIn – Meeting Room Management System

## Overview

BookedIn is a mobile-based meeting room management system developed to streamline the process of booking and managing meeting rooms. The application allows employees to easily schedule meetings while giving administrators full control over approvals and resource allocation.

## Features

* User authentication and secure login
* Browse available meeting rooms
* Select date and time slots for meetings
* Submit booking requests بسهولة
* Admin dashboard for approving or rejecting requests
* Real-time updates for booking status
* Conflict-free scheduling system

## Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** Firebase / REST APIs
* **State Management:** BLoC (if used)
* **Database:** Firestore / Realtime Database

## Architecture

The application follows a scalable architecture approach (Clean Architecture), separating the project into:

* Presentation Layer (UI)
* Domain Layer (Business Logic)
* Data Layer (APIs & Database)

This ensures maintainability, testability, and scalability.

## How It Works

1. User logs into the system
2. Selects a meeting room and desired time slot
3. Submits a booking request
4. Admin reviews the request
5. Request is approved or rejected
6. User receives updated booking status
